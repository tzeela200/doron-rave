# DORON'S RAVE — שלב 1: התקנה ובדיקה

השלב הזה כולל: תשתית Data Layer, Events, Categories, Vendors, Artists, Expenses, ומעטפת מובייל
מלאה (Bottom Navigation, בית, אירועים, פרטי אירוע, הוספת/עריכת הוצאה).

**עדיין לא כלול** (יגיעו בשלבים הבאים): Payments/מקדמות, Income, שכפול אירועים, השוואת אירועים,
חיפוש/סינון, קבצים מצורפים, ולוגו אמיתי (ממתין להעלאה שלך).

---

## שלב 1 — יצירת פרויקט Apps Script

1. גשי ל-**https://script.google.com**
2. לחצי **פרויקט חדש** (New project)
3. תני לפרויקט שם: **DORON'S RAVE**

## שלב 2 — יצירת הקבצים

בפרויקט יש כרגע קובץ אחד בשם `Code.gs` — תשתמשי בו לקובץ הראשון. עבור כל קובץ נוסף:
לחצי על **+** ליד "קבצים" ← בחרי **Script** (לקבצי .gs) או **HTML** (לקבצי .html) ← תני את השם המדויק
(בלי הסיומת, Apps Script מוסיף אותה לבד).

צרי את הקבצים הבאים, בדיוק בסדר ובשמות האלה, והעתיקי לכל אחד את התוכן מהקובץ התואם שקיבלת:

| קובץ ב-Apps Script | סוג | תוכן מהקובץ |
|---|---|---|
| `Code` | Script | Code.gs |
| `Config` | Script | Config.gs |
| `Utils` | Script | Utils.gs |
| `DataService` | Script | DataService.gs |
| `SetupService` | Script | SetupService.gs |
| `EventsService` | Script | EventsService.gs |
| `CategoriesService` | Script | CategoriesService.gs |
| `VendorsService` | Script | VendorsService.gs |
| `ArtistsService` | Script | ArtistsService.gs |
| `ExpensesService` | Script | ExpensesService.gs |
| `Index` | HTML | Index.html |
| `Stylesheet` | HTML | Stylesheet.html |
| `JavaScript` | HTML | JavaScript.html |

**חשוב:** שמות הקבצים ב-Apps Script (העמודה הימנית בטבלה) חייבים להיות מדויקים —
`Code.gs` קורא ל-`HtmlService.createTemplateFromFile('Index')` וכן הלאה, ואם השם לא תואם התוצאה תהיה שגיאה.

## שלב 3 — הרצת ההתקנה החד-פעמית

1. בעורך, בחרי בתפריט הנפתח למעלה (ליד כפתור ה-Debug) את הפונקציה **initializeSystem**
2. לחצי **Run** (▶)
3. בפעם הראשונה Google תבקש הרשאות — אשרי אותן (המערכת ניגשת רק לחשבון Google שלך, ל-Sheets בלבד)
4. בסיום, פתחי את **View → Logs** ותראי שם קישור ל-Spreadsheet שנוצר — זה מקור האמת של המערכת

אפשר להריץ את `initializeSystem` שוב בעתיד בבטחה — היא לא תיצור כפילויות.

## שלב 4 — פריסה כ-Web App

1. למעלה מימין: **Deploy → New deployment**
2. ליד "Select type" — בחרי **Web app**
3. **Execute as:** Me (החשבון שלך)
4. **Who has access:** רק אני (Only myself) — זו מערכת אישית, לא ציבורית
5. לחצי **Deploy**, אשרי הרשאות נוספות אם מתבקש
6. תקבלי קישור (Web App URL) — זה הקישור שתשמרי לשימוש יומיומי מהטלפון (אפשר להוסיף למסך הבית)

בכל פעם שמעדכנים קוד, צריך ליצור **New deployment** נוסף (או "Manage deployments" → עריכה) כדי שהשינויים ייכנסו לתוקף בקישור הקיים.

## בדיקות QA לשלב הזה (לפי סעיף 95 באפיון)

- [ ] יצירת אירוע → נוצרת שורה ב-Events, עם `event_id` ייחודי
- [ ] עריכת אירוע → אותה שורה מתעדכנת, ה-`event_id` לא משתנה
- [ ] ארכוב אירוע → האירוע נעלם מהרשימה אך נשאר ב-Sheet עם `is_archived = TRUE`
- [ ] קטגוריה יחידה בהתקנה נקייה: **אמנים** בלבד
- [ ] יצירת קטגוריה חדשה ("ציליות") מתוך טופס ההוצאה → זמינה מיד באירוע אחר
- [ ] יצירת ספק חדש ("ציליות אברהם") מתוך טופס ההוצאה → זמין לבחירה שוב באירוע חדש
- [ ] יצירת אמן + מילוי "הערות מערכת" → אחרי Refresh, ההערות עדיין שם
- [ ] הוצאה בקטגוריית "אמנים" → השדה מוצג כ"אמן" ולא כ"למי משלמים?"
- [ ] עריכת סכום הוצאה → `expense_id` נשאר זהה, ה-Note הפנימי לא נעלם
- [ ] סה"כ הוצאות באירוע = סכום כל ה-`agreed_amount` הפעילים, כולל אמנים, בלי כפילות
- [ ] Refresh לדף → כל הנתונים נטענים מחדש מה-Sheet (אין תלות בדפדפן)
- [ ] לחיצה כפולה מהירה על "שמור" → נוצרת רשומה אחת בלבד
- [ ] בדיקה במובייל: אין Horizontal Scroll, Bottom Navigation קבוע, ה-Bottom Sheet נפתח ונסגר כמו שצריך

## מה עוד לעשות אחרי הבדיקה

1. תעלי את קובץ הלוגו — אשלב אותו ב-`brand-mark` בקובץ `Index.html` במקום הטקסט הזמני
2. נמשיך לשלב הבא: **Payments (מקדמות ותשלומים) + Income (הכנסות)** — זה מה שישלים את "שולם/נותר" בפועל, שכרגע מוצג כ-0/סה"כ ההוצאה בהתאם
3. אחר כך: שכפול אירועים, השוואת אירועים, חיפוש/סינון, קבצים מצורפים

תגידי לי כשסיימת להתקין ולבדוק, ונמשיך.
