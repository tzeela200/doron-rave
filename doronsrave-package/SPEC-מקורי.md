אפיון מלא לבנייה — DORON'S RAVE
1. מטרת הפרויקט
בנה אפליקציית Web מלאה, אמיתית ועובדת בשם:
DORON'S RAVE
זוהי מערכת אישית של משתמשת אחת לניהול כלכלי ותפעולי של מסיבות ואירועים.
המטרה היא לאפשר לנהל בצורה פשוטה מאוד, בעיקר מהטלפון:
•	אירועים
•	הוצאות
•	קטגוריות
•	ספקים
•	אמנים
•	מקדמות ותשלומים
•	מועדי תשלום
•	הערות פנימיות
•	הכנסות
•	מאזן אירוע
•	השוואה בין אירועים
זו אינה מערכת ERP, אינה מערכת הנהלת חשבונות, אינה מערכת Ticketing ואינה מערכת ארגונית.
המערכת צריכה להיות מהירה, פשוטה, אינטואיטיבית ולהרגיש כמו אפליקציה פרטית שנבנתה במיוחד עבור DORON'S RAVE.

6. התקנה ראשונית
צור פונקציית Setup חד־פעמית, לדוגמה:
initializeSystem()
היא צריכה:
1.	ליצור Spreadsheet חדש או להתחבר ל־Spreadsheet שהוגדר.
2.	ליצור את כל ה־Tabs הנדרשים.
3.	ליצור Headers.
4.	להגדיר פורמט תאריכים ומספרים.
5.	ליצור את קטגוריית ברירת המחדל "אמנים".
6.	ליצור את אמצעי התשלום הראשוניים.
7.	לא ליצור שום Event, Expense, Vendor, Artist או Income פיקטיביים.
8.	להיות Idempotent — הפעלה חוזרת שלה לא תיצור כפילויות.
שמור מזהים טכניים כגון Spreadsheet ID באמצעות Script Properties ולא בקוד ה־Frontend.
